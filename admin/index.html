StreamElements commands

Use this instead of Connect chat to run duels through your StreamElements bot. Each action is a StreamElements custom command; its bot posts the reply.

Set it up in StreamElements

  1. Turn off the built-in Duel game. At streamelements.com, open the dashboard, go to Chat bot, then Modules, and switch off Duel. Or type !module duel disable in chat. Its !duel, !accept and !deny would answer at the same time as ours, which is why accepting is !fight.
  2. Optional: rename commands here first. Change a name in the table below (for example !duel for Challenge) and click Save names. The bot replies use your names.
  3. Add one command per row. In StreamElements go to Chat bot, then Commands, open the Custom commands tab and click Add new command. Then:
    • Command name: the name from the table without the !, for example challenge.
    • Reply: click Copy reply in that row and paste it. Paste the whole line; don't change it.
    • Advanced settings: set both cooldowns (user and global) to 0. The game has its own cooldowns, and a bot cooldown silently drops moves.
    • Click Activate command.
  4. If a command with that name already exists (StreamElements says the name is taken): find it in the Custom commands list, click its edit (pencil) button, select everything in Reply, delete it, paste the copied reply, and click Save. Default commands can't be edited; turn them off or pick another name here.
  5. Click Use StreamElements below once all 3 are added.
  6. Test it: type !decline in your chat. The bot should answer "you have no pending challenge". If it says "wrong key", copy the reply again.

Add commands in the dashboard, not with !command add in chat: the reply contains the key, and chat would show it to every viewer.
