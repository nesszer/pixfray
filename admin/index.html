StreamElements commands

Use this instead of Connect chat to run duels through your StreamElements bot. Each action is a StreamElements custom command; its bot posts the reply.

  1. If you use the StreamElements Duel module, turn it off (Chat bot, Modules), because it owns !duel, !accept and !deny.
  2. Pick a command name for each action below and click Save names.
  3. In StreamElements (Chat bot, Custom commands), add each command with the reply shown. Then click Use StreamElements.

ActionCommand nameStreamElements replyCopy

The reply contains this channel's key. Anyone who sees it can send duel moves as any viewer, so keep it to the broadcaster and mods; click New key if it leaks, then paste the commands again. StreamElements only calls the site on commands, so characters appear when a viewer uses one.
