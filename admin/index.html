Stream setup

Do these in order. Each step turns Done by itself within 10 seconds of working, so keep this tab open while you set things up. The last step is optional.

  2. …

    Turn off the StreamElements Duel module

    StreamElements has its own Duel game. Its !duel, !accept and !deny would answer at the same time as PixFray. At streamelements.com go to Chat bot, then Modules, and switch off Duel, or type !module duel disable in your chat.

  3. …

    Add the chat commands to StreamElements

    1. At streamelements.com go to Chat bot, then Commands, open Custom commands and click Add new command.
    2. Command name: the name from the table without the !, for example challenge.
    3. Response: click Copy reply in that row and paste it. Don't change it.
    4. Under Advanced settings set both cooldowns to 0, then click Activate command.
    5. Repeat for each row, then type !decline in your chat. The row turns Working when it arrives.
    What it doesCommand nameStatusResponse to paste

    More about these commands
    • Renaming: change a name in the table and click Save names before adding it in StreamElements. Bot replies use your names. Accepting is !fight because the Duel module owns !accept.
    • The name is taken: find that command under Custom commands, click its edit (pencil) button, replace the whole Response with the copied one and click Save. Default commands can't be edited; turn them off or pick another name here.
    • Optional rows: !ranks, !elo and !fray. !fray tells viewers how to join.
    • Remind chat how to join: add a StreamElements timer every 15 to 20 minutes and paste the text from Copy timer message. PixFray never posts on its own.
    • Use StreamElements makes StreamElements the chat source by hand. The first command that arrives does the same.

    Add commands in the StreamElements dashboard, not with !command add in chat: the response contains this channel's key, and chat would show it to every viewer. Anyone with the key can send duel moves as any viewer, so click New key if it leaks, then paste every response again.

If something doesn't work

The overlay is blank in OBS
  1. Click Copy link again and paste the whole link into the Browser Source URL.
  2. Set the source to 1920 × 1080.
  3. Turn off "Shutdown source when not visible".
  4. Right-click the source and choose Refresh. "Add the overlay to OBS" above turns to Done within 10 seconds.
Two bots answer the same command

The StreamElements Duel module is still on. Switch it off under Chat bot, then Modules, or type !module duel disable in chat.

A command answers "wrong key"

The response in StreamElements is old or from another site. Copy that row's response again from the table and replace the old one.

Test !checkin while offline

For 15 minutes, !checkin answers while the stream is offline and shows what a viewer would get. Nothing is saved: no points, no streak.
